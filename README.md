# Insurance Risk Analytics

## Overview
Analyzing historical car insurance data for AlphaCare Insurance Solutions (ACIS) to identify low-risk customers and optimize premium pricing strategy.

## Task 1: EDA (Interim Submission) 
- Dataset: 1,000,098 policies (Oct 2013 – Aug 2015)
- 9 South African provinces analyzed
- Claim rate: 0.3%
- Average premium: ZAR 61.91
- Top province by premium: KwaZulu-Natal (ZAR 77.80)

## Tools Used
- Python, pandas, matplotlib, seaborn, DVC
